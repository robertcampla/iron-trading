# Home visual approval checklist

Revisar únicamente el Home antes de avanzar:

- Coincidencia general con la referencia aprobada.
- Proporción sidebar / contenido.
- Hero y atmósfera visual.
- Paleta graphite / copper.
- Jerarquía de cuentas fondeadas.
- Estado del sistema.
- Autopilot Global.
- Espaciado, bordes y tipografía.

No se considera aprobado hasta confirmación explícita de Roberto.
