# IRON TRADING — Design System

## Estado
Baseline visual: Home aprobado el 13-Sep-2026.

## Dirección visual
Aplicación SaaS financiera premium. No debe convertirse en un dashboard genérico ni en una copia visual de NinjaTrader, HYDRA u OMEGA.

## Paleta conceptual
- Obsidian / Graphite: fondos principales.
- Charcoal / Titanium: superficies y paneles.
- Soft White: texto principal.
- Copper / Warm Gold: identidad IRON TRADING, selección y acciones primarias.
- Emerald: beneficio, estados saludables y LONG.
- Signal Red: pérdida, riesgo crítico y SHORT.
- Amber: advertencias.

Verde y rojo se reservan para significado financiero/operativo; no se usan como decoración.

## Home aprobado
El Inicio debe priorizar:
1. Saludo/resumen global.
2. Capital total, P&L diario y margen de seguridad.
3. Mis Cuentas de Fondeo como contenido protagonista.
4. Estado del sistema.
5. Iron Autopilot Global con flujo Mercado → Estrategia → Riesgo → Ejecución.
6. Resumen diario.
7. Rendimiento y distribución de operaciones.

## Regla de cambio visual
No modificar estructura principal, identidad cromática o lenguaje visual de la baseline sin aprobación explícita.
